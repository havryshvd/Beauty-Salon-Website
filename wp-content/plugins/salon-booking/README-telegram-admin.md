# Панель администратора в Telegram

Бот использует один личный chat ID из раздела WordPress «Запись в салон → Настройки → Telegram». Только этот аккаунт получает уведомления и может управлять записями. Группы и другие пользователи не получают доступ к панели. Команда `/id` позволяет узнать свой chat ID при первоначальной настройке.

Администратор отправляет `/menu` или `/start`. Главное меню содержит «Сегодня по мастерам», «Выбрать дату» и «Новая запись». После выбора дня бот показывает мастеров и число записей у каждого. Записи выбранного мастера идут по времени; из списка открывается карточка клиента. Дату можно выбрать кнопками или написать сообщением в формате `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`.

В карточке ожидающей записи доступны подтверждение, перенос и отклонение. Для подтверждённой записи доступны перенос и отмена. При переносе бот показывает только свободные даты и время, а перед сохранением проверяет доступность слота снова.

«Новая запись» последовательно запрашивает услугу, мастера, свободные дату и время, имя и телефон клиента. Телефон можно отправить контактом Telegram. Перед сохранением бот показывает все данные для проверки. Запись, созданная администратором, сразу получает статус «Подтверждена». Повторное нажатие старой кнопки сохранения не создаёт дубль. Команда `/cancel` возвращает в главное меню.

Для быстрого отклика настройте запуск `tools/telegram-worker.php` на своём сервере. Токен и chat ID вводятся только через настройки WordPress и не входят в репозиторий.
