=== Запись в салон ===
Версия: 1.3.1
Требования: WordPress, PHP 8.0+, MySQL/MariaDB с InnoDB.

Раздел «Запись в салон → Обзор» показывает записи на сегодня и ближайшие семь дней, ожидающие заявки, активных мастеров, ближайшие визиты и готовность услуг, расписания, контактов и Telegram. На странице «Записи» есть быстрые фильтры.

Владелец с ролью WordPress «Администратор» может управлять всеми разделами. Для сотрудника создайте пользователя с ролью «Администратор салона»: ему доступны записи, услуги, мастера и расписание без общих настроек WordPress и токена Telegram. Назначайте эту роль только сотрудникам, которым можно видеть имена и телефоны клиентов.

Telegram: откройте личный чат с ботом, отправьте /id, сохраните токен и полученный chat ID в «Настройках», затем отправьте тестовое сообщение. После успешного теста панель покажет имя подключённого бота и время проверки. Для быстрого отклика запустите фоновый PHP-процесс на своём сервере.

Плагин работает отдельно от других систем бронирования. Данные хранятся в таблицах с префиксом sbk_ и префиксом базы WordPress.

После активации откройте «Запись в салон» в панели управления:
1. Добавьте услуги, их длительность и цену. Цена 0 означает «цена уточняется» в форме до заполнения прайса.
2. Добавьте мастеров и отметьте услуги каждого мастера.
3. Заполните недельное расписание мастеров. Перерывы вводятся по одному на строку, например 13:00-14:00. Исключение на дату заменяет расписание соответствующего дня недели; отметьте «Выходной» для закрытого дня.
4. При необходимости измените шаг времени, минимальный срок до записи, горизонт календаря и паузу между клиентами в «Настройках».
5. Добавьте шорткод [salon_booking] в виджет «Шорткод» Elementor.

Стили публичной формы находятся в assets/booking.css. Все классы формы начинаются с sbk-. Основные цвета, граница и радиус задаются переменными --sbk-accent, --sbk-border, --sbk-radius. Менять внешний вид можно CSS сайта без изменения PHP и JavaScript.

Telegram: пустое поле токена сохраняет прежний токен. Для уведомлений каждого мастера добавьте его личный chat ID в карточке мастера. Сначала каждый адресат должен открыть личный чат с ботом и отправить /id или «айди»: бот ответит его chat ID. Администратор и мастер получают сообщения о новых, изменённых и закрытых записях. Отправка уведомления запускается сразу после записи, а локальный фоновый обработчик проверяет очередь и ответы бота каждые несколько секунд. При ошибке очередь повторяет отправку. В личном чате кнопки позволяют подтвердить, отменить, завершить запись и перенести её на другую свободную дату и время того же мастера. После обработки старые кнопки убираются, а актуальные появляются в новом уведомлении. Для смены мастера, услуги или контактных данных откройте запись в админке. Кнопки не работают в групповом чате. Не подключайте к этому же боту другой webhook или обработчик getUpdates.

На сервере настройте системный вызов wp-cron.php. Для быстрого отклика бота запустите отдельный обработчик tools/telegram-worker.php или настройте HTTPS webhook.

Клиентские записи получают статус «Ожидает». Администратор может подтвердить, отменить или завершить запись, а также изменить услугу, мастера, дату, время, имя и телефон в действующей записи. Изменение времени или мастера проходит повторную проверку доступности. Отменённые и завершённые записи не занимают слоты. Ручные записи сразу подтверждаются и проходят ту же проверку доступности.

Для защиты от двойного бронирования проверка свободного слота и запись выполняются под блокировкой MySQL для выбранного мастера. Публичный API отдаёт только каталог и свободное время; имя и телефон доступны только в админке.
